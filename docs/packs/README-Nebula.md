# Nebula for Adventure Game Studio Editor

Unofficial community port of [Nebula](https://marketplace.visualstudio.com/items?itemName=ChirtleLovesDolls.nebula-theme) (ChirtleLovesDolls) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [ChirtleLovesDolls](https://github.com/eating-coleslaw) (eating-coleslaw) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Cranberry `#E34F8C` |

This is **not** an official Nebula release. The VS Code extension can generate variants from settings; this AGS port maps the **default** Nebula palette (fresh colors on a dark, cold slate).

## File

| File | Theme |
|---|---|
| `[M] Nebula.json` | Nebula (defaults) |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose **Nebula**
4. Restart the editor
