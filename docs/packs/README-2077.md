# 2077 for Adventure Game Studio Editor

Unofficial community port of [2077 theme](https://marketplace.visualstudio.com/items?itemName=Endormi.2077-theme) (Cyberpunk 2077-inspired) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [Endormi](https://github.com/endormi) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Hot pink `#ff2592` (yellow `#ffd400` used in syntax) |

This is **not** an official Endormi / 2077 theme release, and is not affiliated with CD Projekt RED or *Cyberpunk 2077*.

## File

| File | Theme |
|---|---|
| `[M] 2077.json` | 2077 |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose **2077**
4. Restart the editor
