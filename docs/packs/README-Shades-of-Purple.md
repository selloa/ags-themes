# Shades of Purple for Adventure Game Studio Editor

Unofficial community port of [Shades of Purple](https://marketplace.visualstudio.com/items?itemName=ahmadawais.shades-of-purple) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [Ahmad Awais](https://github.com/ahmadawais) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Contrast yellow `#FAD000` |

This is **not** an official Shades of Purple release.

## File

| File | Theme |
|---|---|
| `[M] Shades of Purple.json` | Shades of Purple |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose **Shades of Purple**
4. Restart the editor
