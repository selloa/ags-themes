# GitHub Themes for Adventure Game Studio Editor

Unofficial community port of [GitHub's VS Code themes](https://github.com/primer/github-vscode-theme) (Primer) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Palette / original by** | [Primer](https://github.com/primer) / [github-vscode-theme](https://github.com/primer/github-vscode-theme) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Blue `#2f81f7` (dark) / `#0969da` (light) |

This is **not** an official GitHub or Primer release. Colors follow Primer dark/light default tokens.

## Files

| File | Flavor |
|---|---|
| `[M] GitHub Dark.json` | Dark Default |
| `[M] GitHub Light.json` | Light Default |

## Install

1. Place the JSON file(s) in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose **GitHub Dark** or **GitHub Light**
4. Restart the editor
