# Falcon for Adventure Game Studio Editor

Unofficial community port of [Falcon VS Code Themes](https://github.com/panxiaoan/falcon-vscode-themes) (Falcon Relaxing-Eyes) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [Xiaoan Pan](https://github.com/panxiaoan) (panxiaoan) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Variants** | 12 solid-color themes (8 light, 4 dark) |

This is **not** an official Falcon release. Colors are mapped from the upstream YAML sources under `src/light` and `src/dark`.

## Install

1. Place the JSON files in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose a Falcon variant
4. Restart the editor
