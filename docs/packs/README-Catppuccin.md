# Catppuccin for Adventure Game Studio Editor

Unofficial community port of the [Catppuccin](https://catppuccin.com/) color palette for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Palette by** | [Catppuccin](https://github.com/catppuccin/catppuccin) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Mauve (tabs, status bar, links, highlights) |

This is **not** an official Catppuccin organization port.

## Files

| File | Flavor |
|---|---|
| `[M] Catppuccin Mocha.json` | Mocha (darkest) |
| `[M] Catppuccin Macchiato.json` | Macchiato |
| `[M] Catppuccin Frappe.json` | Frappe |
| `[M] Catppuccin Latte.json` | Latte (light) |

## Install

1. Place the JSON files in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose a Catppuccin flavor
4. Restart the editor
