# SidWave '84 for Adventure Game Studio Editor

A SynthWave-inspired AGS Editor theme by [selloa](https://github.com/selloa) — a **clone/homage**, not a 1:1 port.

| | |
|---|---|
| **AGS theme by** | [selloa](https://github.com/selloa) |
| **Color inspiration** | [SynthWave '84](https://marketplace.visualstudio.com/items?itemName=RobbOwen.synthwave-vscode) by [Robb Owen](https://github.com/robb0wen) |
| **Format** | Modern (`[M]`) — AGS **3.6.0.36+** |
| **Accent** | Hot pink `#ff7edb` (tabs, status bar); coral `#f97e72` for captions/caret |

### Why “SidWave”?
The original SynthWave '84 is famous for its optional **Neon Dreams** glowing text. AGS Editor themes can only set solid colors — no glow — so this pack uses a clearly different name while keeping the same neon-sunset palette vibe.

## File

| File | Theme name in AGS |
|---|---|
| `[M] SidWave 84.json` | SidWave '84 |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File → Preferences → Color Theme**
3. Choose **SidWave '84**
4. Restart the editor
