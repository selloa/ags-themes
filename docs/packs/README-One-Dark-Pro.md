# One Dark Pro for Adventure Game Studio Editor

Unofficial community port of [One Dark Pro](https://github.com/Binaryify/OneDark-Pro) (Atom One Dark) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [Binaryify](https://github.com/Binaryify) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Blue `#61afef` / caret `#528bff` |

This is **not** an official One Dark Pro release.

## File

| File | Theme |
|---|---|
| `[M] One Dark Pro.json` | One Dark Pro |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose **One Dark Pro**
4. Restart the editor
