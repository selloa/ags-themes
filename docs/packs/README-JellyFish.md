# JellyFish for Adventure Game Studio Editor

Unofficial community port of [JellyFish](https://marketplace.visualstudio.com/items?itemName=PawelBorkar.jellyfish) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [Pawel Borkar](https://github.com/pawelborkar) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |
| **Accent** | Cyan `#00ffff` (pink `#ff0080` secondary) |

This is **not** an official JellyFish release. Deep-ocean dark UI with neon accents from the shared JellyFish palette.

## File

| File | Theme |
|---|---|
| `[M] JellyFish.json` | JellyFish |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose **JellyFish**
4. Restart the editor
