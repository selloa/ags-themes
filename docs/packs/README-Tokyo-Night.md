# Tokyo Night for Adventure Game Studio Editor

Unofficial community port of [Tokyo Night](https://github.com/enkia/tokyo-night-vscode-theme) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [enkia](https://github.com/enkia) |
| **Format** | Modern (`[M]`) - AGS **3.6.0.36+** |

This is **not** an official Tokyo Night port. Colors follow the VS Code Tokyo Night / Storm / Light palettes.

## Files

| File | Flavor | Accent |
|---|---|---|
| `[M] Tokyo Night.json` | Night (default) | Blue `#7aa2f7` |
| `[M] Tokyo Night Storm.json` | Storm (lighter dark) | Blue `#7aa2f7` |
| `[M] Tokyo Night Light.json` | Light (day) | Blue `#2e7de9` |

## Install

1. Place the JSON files in `%LocalAppData%\AGS\Themes`
2. In AGS: **File -> Preferences -> Color Theme**
3. Choose a Tokyo Night flavor
4. Restart the editor
