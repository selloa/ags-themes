# Halcyon for Adventure Game Studio Editor

Unofficial community port of [Halcyon](https://marketplace.visualstudio.com/items?itemName=brittanychiang.halcyon-vscode) for the [Adventure Game Studio](https://www.adventuregamestudio.co.uk/) Editor.

| | |
|---|---|
| **AGS port by** | [selloa](https://github.com/selloa) |
| **Original theme by** | [Brittany Chiang](https://github.com/bchiang7) |
| **Format** | Modern (`[M]`) — AGS **3.6.0.36+** |
| **Accent** | Gold `#ffcc66` |

This is **not** an official Halcyon release. Halcyon’s syntax & workbench colors are based on Ayu Mirage.

## File

| File | Theme |
|---|---|
| `[M] Halcyon.json` | Halcyon |

## Install

1. Place the JSON file in `%LocalAppData%\AGS\Themes`
2. In AGS: **File → Preferences → Color Theme**
3. Choose **Halcyon**
4. Restart the editor
